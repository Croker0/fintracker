# Требования к продукту «ФинТрекер»

**Версия:** 1.0  
**Автор:** Ибрагимов (аналитик)  
**Статус:** реализовано в v1.0.0

## 1. Цель и ценность

Люди теряют контроль над повседневными тратами, потому что записывать расходы долго,
а существующие приложения перегружены функциями. «ФинТрекер» даёт **быстрый ввод в 3 касания**
и сразу показывает, **куда уходят деньги** — без регистрации и подключения к сети.

**Ценностное предложение:** «Записал трату — увидел картину месяца».

## 2. Аудитория

| Сегмент | Потребность | Сценарий |
|---|---|---|
| Студенты | контролировать небольшие ежедневные траты | записать обед и проезд, посмотреть остаток на неделю |
| Молодые специалисты | понимать структуру расходов | зарплата, аренда, продукты; топ категорий и динамика |
| Семьи | общий учёт и отчёты | выгрузка CSV за месяц, анализ крупных покупок |

## 3. Анализ аналогов

| Продукт | Сильная сторона | Слабость для нашей аудитории |
|---|---|---|
| CoinKeeper | красивый визуал, синхронизация | платная подписка, сложный старт |
| Money Lover | мощные отчёты | перегруженный интерфейс |
| Дзен-мани | автоматизация | требует подключения банка, не офлайн |

**Вывод:** ниша — лёгкое офлайн-приложение с быстрым вводом и понятной аналитикой
на русском языке.

## 4. Границы версии 1.0

**Входит:** ручной учёт расходов/доходов, категории, теги, периоды, графики, экспорт CSV/JSON,
ежедневное напоминание, локальное автосохранение, светлая/тёмная тема.

**Не входит:** банковские интеграции, мультивалютность, совместный доступ, облачный аккаунт,
бюджеты и лимиты, регулярные платежи.

## 5. User stories и критерии приёмки

### US-01. Быстро добавить расход
**Как** пользователь, **я хочу** добавить расход за несколько секунд, **чтобы** не откладывать учёт.

- [x] На главной и на экране операций есть кнопка «Добавить».
- [x] Форма открывается с выбранным типом «Расход».
- [x] Сумма принимает `1450`, `1 450,50`, `1450.50`; отрицательные и нулевые значения отклоняются.
- [x] Без выбранной категории сохранение не происходит и показывается подсказка.
- [x] После сохранения операция сразу появляется в списке и в графиках.

### US-02. Учесть доход
**Как** пользователь, **я хочу** отмечать зарплату и подработки, **чтобы** видеть реальный баланс.

- [x] Переключатель «Доход» меняет список категорий на доходные.
- [x] Сумма дохода отображается зелёной и со знаком `+`.
- [x] Баланс = доходы − расходы; отрицательный баланс выделяется цветом.

### US-03. Найти операцию
**Как** пользователь, **я хочу** найти трату по заметке, тегу или категории.

- [x] Поиск работает по всем трём полям без учёта регистра.
- [x] Фильтры «Все / Расходы / Доходы» и категория комбинируются с поиском.
- [x] При пустом результате показывается пустое состояние с кнопкой добавления.

### US-04. Понять структуру расходов
**Как** пользователь, **я хочу** видеть доли категорий и динамику, **чтобы** осознанно менять привычки.

- [x] Кольцевая диаграмма показывает топ-5 категорий + «Другое».
- [x] Легенда содержит процент каждой категории.
- [x] Столбчатый график показывает расходы по дням (неделя/месяц) или месяцам (год/всё время).
- [x] При отсутствии данных графики показывают пустое состояние, а не падают.

### US-05. Управлять категориями
**Как** пользователь, **я хочу** добавлять свои категории с иконкой и цветом.

- [x] Название обязательно и уникально в рамках типа.
- [x] Можно выбрать эмодзи и цвет.
- [x] Нельзя удалить стандартную категорию или категорию с операциями.
- [x] Нельзя менять тип категории, если в ней есть операции.

### US-06. Получить отчёт
**Как** пользователь, **я хочу** выгрузить операции в CSV/JSON, **чтобы** анализировать их в Excel
или сохранить резервную копию.

- [x] CSV открывается в русском Excel: UTF-8 BOM, `;`, десятичная запятая.
- [x] JSON содержит версию схемы, дату выгрузки, итоги и операции с тегами.
- [x] Файл передаётся через системное «Поделиться» с корректным MIME-типом.

### US-07. Не забыть записать траты
**Как** пользователь, **я хочу** ежедневное напоминание в выбранное время.

- [x] Время настраивается (по умолчанию 20:00).
- [x] Напоминание можно выключить.
- [x] На Android 13+ запрашивается разрешение на уведомления.
- [x] Напоминание переживает перезагрузку устройства (WorkManager).

## 7. Нефункциональные требования

| NFR-07 | Контраст текста ≥ 4.5:1 в светлой и тёмной теме | проверка палитры |
| NFR-08 | Unit-тесты на деньги, агрегации и список | `testDebugUnitTest` |

## 8. Метрики успеха (для защиты проекта)

- Время добавления операции — **< 15 секунд**.
- Доля операций с категорией — **100%** (категория обязательна).
- Понятность главного экрана — не менее **4 из 5** в мини-опросе 5 человек.
- Все сценарии приёмки US-01…US-07 пройдены.

## 9. Тест-кейсы приёмки

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-01 | Добавить расход 1 450 ₽, категория «Продукты» | Строка появилась, баланс уменьшился на 1 450 ₽ |
| TC-02 | Ввести `0` или `-5` | Ошибка «Введите сумму больше нуля» |
| TC-03 | Сохранить без категории | Подсказка «Выберите категорию», форма не закрыта |
| TC-04 | Переключить период «Неделя» → «Год» | Меняются суммы и точки графика |
| TC-05 | Поиск «кофе» | Остаются только операции с «кофе» в заметке/категории/теге |
| TC-06 | Удалить операцию из редактора | Строка исчезла, итоги пересчитаны |
| TC-07 | Удалить категорию с операциями | Сообщение об ошибке, категория осталась |
| TC-08 | Экспорт CSV | Файл открывается в Excel, суммы с запятой, кириллица корректна |
| TC-09 | Выключить и включить напоминание | Работа отменяется и пересоздаётся без дублей |
| TC-10 | Повернуть экран на главной | Данные и выбранный период сохраняются |
| TC-11 | Включить тёмную тему | Все экраны читаемы, графики видны |
| TC-12 | Очистить операции | Пустые состояния на главной и в аналитике, приложение не падает |
